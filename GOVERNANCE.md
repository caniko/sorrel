# Governance

Sorrel is maintained by [Can H. Tartanoglu (`caniko`)](https://github.com/caniko). The maintainer makes final decisions about project scope, merges and releases. Single-maintainer governance does not mean single-author development: the [commit history](https://github.com/caniko/sorrel/commits/trunk/) includes commits from external contributors.

Anyone can propose a change through a GitHub issue or pull request. Use [CONTRIBUTING.md](CONTRIBUTING.md) for the review and verification workflow and [SECURITY.md](SECURITY.md) for private vulnerability reports.
