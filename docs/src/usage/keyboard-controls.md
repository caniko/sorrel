# Keyboard Controls

| Key | Action |
|-----|--------|
| `G` | Label the selected cluster as good. |
| `M` | Label the selected cluster as MUA. |
| `N` | Label the selected cluster as noise. |
| `U` | Label the selected cluster as unsorted. |
| `J` / down arrow / right arrow | Select the next cluster. |
| `K` / up arrow / left arrow | Select the previous cluster. |
| `H` | Pan the trace window backward. |
| `L` | Pan the trace window forward. |
| `Cmd-Z` / `Ctrl-Z` | Undo placeholder in V1. |

Label changes are journaled to SQLite before the in-memory session changes.
