# Citing Sorrel

If you use Sorrel in your work, cite the release you used. The canonical
metadata is [`CITATION.cff`](https://github.com/caniko/sorrel/blob/trunk/CITATION.cff)
at the repository root; GitHub's "Cite this repository" button reads the same
file.

BibTeX, as `cffconvert -f bibtex` emits it from `CITATION.cff` (rename the
key):

```bibtex
@misc{YourReferenceHere,
author = {Tartanoglu, Can H.},
month = {11},
title = {Sorrel},
url = {https://sorrel.tartanoglu.com/},
year = {2026}
}
```

Regenerate it after editing `CITATION.cff`:

```sh
nix shell nixpkgs#uv -c uvx cffconvert --validate
nix shell nixpkgs#uv -c uvx cffconvert -f bibtex
```

## Acknowledgments

Sorrel was developed and evaluated on tetrode recordings from
[CINPLA](https://www.mn.uio.no/ibv/english/research/sections/fyscell/cinpla/about/),
the Centre for Integrative Neuroplasticity at the University of Oslo, sorted
with Kilosort 2 and curated in phy. They were used to verify spike rescue end
to end and measure its speed and recall, and to evaluate `sorrel auto` on
tetrode geometry. The double-blind curation bench also scores
Sorrel against human-curated sorts that the repository identifies only by
opaque session ids.

No recording data is distributed with Sorrel. The phy fixtures in
`release/fixtures/` are synthetic, generated by
`crates/sorrel-data/tests/tiny_phy_fixture.rs`.
