# phy parity

Sorrel aims to do everything phy's TemplateGUI does. The target is
cortex-lab/phy master (v2.1, 2026). This page lists every phy view, action
and shortcut against its Sorrel equivalent. Each row has one of these
statuses:

- **done** — available now. The test column names the check that covers it.
- **planned** — not built yet.
- **excluded** — deliberately left out; the row says why.

## Differences that stay

- **SortingAnalyzer PCs.** SpikeInterface's `principal_components`
  extension only holds the `random_spikes` subset (at most 500 spikes per
  unit; on one real 0.105 analyzer, 32 425 of 210 884 spikes). A lasso
  split on it would leave every other spike behind. Sorrel therefore
  computes its own PCs for SortingAnalyzer folders, which covers every
  spike.
- **Missing PCs.** phy shows no FeatureView without `pc_features.npy`;
  Sorrel computes PCs instead.
- **Custom labels in `curation.json`.** These are written as `name=value`
  tags, not as SpikeInterface label keys.
- **Plugins and the IPython console.** Both are excluded. Scripting goes
  through `sorrel-py` and `sorrel serve`.
