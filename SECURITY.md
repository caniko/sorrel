# Security policy

## Supported versions

| Version        | Scope                                               |
| -------------- | --------------------------------------------------- |
| `0.4.x`        | Current release series                              |
| `trunk`        | Current development branch; not a published release |
| Older releases | Not supported                                       |

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/caniko/sorrel/security/advisories/new) if the repository offers **Report a vulnerability**. If the button is unavailable, private reporting is not enabled. Ask the [maintainer](https://github.com/caniko) for a private channel. If your only way to reach them is a blank public issue, ask for private contact details without mentioning the affected component or including any vulnerability details.

In the private report, include the affected version or commit, platform, impact and a minimal reproducer if available. Do not send credentials or private recordings. Use the public issue forms for ordinary bugs and compatibility problems, not vulnerability details.
